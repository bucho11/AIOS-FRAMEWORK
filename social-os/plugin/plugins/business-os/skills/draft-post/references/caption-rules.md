# Caption rules — 2026, local service business, Instagram + Facebook

## Shape

```
Line 1   HOOK + local/service keyword           ← must land inside 125 characters
Lines 2–4  value, quick proof, or a short story  ← one idea per line
Last line  ONE call to action
(hashtags: 3–5 local, here or in the first comment — never both)
```

- **First 125 characters** are what shows before "more" on Instagram. Facebook
  truncates around 480. The promise, the service, and the place go first.
- **Short to medium.** Scannable. Longer only when the format is a story-style
  carousel caption and the voice supports it.
- **One CTA, last line.** The post reads naturally first and converts second.
- **Line breaks** between ideas; **emoji** only if the voice profile allows, and
  purposeful (a marker, not decoration).
- **Hashtags:** 3–5, small and local (`#RenoNanny #TahoeFamilies`), plus one
  branded. Never generic giants. Either at the end of the caption or in the first
  comment.
- **Links:** Instagram captions have no live links — put them in the first comment.
  Facebook captions can carry a link.
- **Alt text:** plain description of the image with the main topic word; the
  publisher can pass it where the platform supports it.
- **Location tag:** on every locally relevant post.

## Per-platform differences worth keeping

| | Instagram | Facebook |
|---|---|---|
| Hook visible | ~125 chars | ~480 chars |
| Links | first comment only | in caption OK |
| Hashtags | 3–5, caption or first comment | fewer, 1–3 |
| Image | JPEG/PNG ≤ 8 MB | JPEG/PNG ≤ 4 MB (publisher compresses) |
| Reel | ≤ 90 s | ≤ 60 s → **write to 60 for cross-posts** |
| Story | no caption shown | 120 s video max |

## CTA forms that convert locally

- "DM **CARE** for this month's availability"
- "Comment **CHECKLIST** and I'll send you our hiring guide"
- "Book a free 15-minute family call — link in the first comment"
- "Call or text us today" (Facebook)

## Testimonial lines

Quote or paraphrase without changing meaning. Disclose any incentive in the
caption itself, plainly ("shared with permission; this family received a
referral credit"). Never composite two families into one quote.
